# Prompts Used

This file documents AI assistance used while building the assessment.

## Example prompt 1

Prompt:

> Generate a Rails API-only architecture for an employee and salary analytics system with PostgreSQL full-text search.

Why used:

- To speed up the initial structure and identify the right folders and responsibilities.

What changed after review:

- Search was implemented with PostgreSQL FTS and GIN indexing instead of Elasticsearch.
- Controllers were kept thin and service objects were introduced.

## Example prompt 2

Prompt:

> Suggest an optimized seed strategy for 10,000 employees in Rails.

Why used:

- To avoid row-by-row inserts and keep seed time predictable.

What changed after review:

- `insert_all` batching was chosen.
- Names are generated by combining values from `first_names.txt` and `last_names.txt`.

## Example prompt 3

Prompt:

> Design a React dashboard for HR salary insights with modern motion and virtualization.

Why used:

- To shape a futuristic but usable UI for the HR persona.

What changed after review:

- React Query owns server state.
- Zustand owns only local UI state.
- Virtualized employee tables are used for performance.
